# Changelog

## v1.2.6

- **Documentation & Cleanup:** Eliminated bare `catch {}` blocks across `GpuPolarisAccelerator` (`TryCudaCleanup`) and `StringKernels.Parsing` (`JsonException` / `InvalidOperationException` with `Trace.TraceWarning`), standardized documentation under `docs/`, and replaced static tables with reproducible `FullSuiteBenchmark` measurements covering I/O and GPU vector math.
- **Hardened GPU & SIMD Acceleration:** Stack-allocated CUDA kernel parameter marshaling (`stackalloc void*[]`), overflow-checked `(nuint)` device sizing, bounded CUDA stream pooling with `ReleaseGpuResources()`, `TensorPrimitives` vectorized unary math fallbacks, and explicit `NotSupportedException` / `PlatformNotSupportedException` handling for `GpuTarget.DualGpu` and `GpuTarget.Amd`.
- **Full Native AOT Compatibility (`IsAotCompatible=true`, `EnableTrimAnalyzer=true`, `TieredPGO=true`) & `TreatWarningsAsErrors=true`:** Replaced runtime lambda compilation (`LambdaExpression.Compile()`), `Expression.NewArrayInit`, `Activator.CreateInstance`, `Type.GetType`, reflection-based plan dispatch, and reflection-based JSON serialization with static AST evaluation (`ExprLambdaEvaluator`), sealed plan nodes, typed series factories, and `Utf8JsonWriter`.
- **Sound `QueryOptimizer` Rules:** Guarded `Filter -> Select` pushdown against aggregations, windows, and computed expressions (with alias rewriting on pass-through columns), guarded `Limit -> Select` against row-collapsing projections, resolved `DataFrameOp` / `ScanJsonOp` / `SelectOp` / `RenameOp` schemas in `Filter -> Join`, preserved `SortOp` / `GroupByOp` / `DropNullsOp` / `UniqueOp` columns during projection pushdown, and restricted join reordering to `JoinType.Inner` while preserving exact output column order.
- **Multi-Column Joins, Null-Aware `Unique()` & Stable Multi-Column Radix `Sort`:** Generalized `DataFrame.Join` across hashable single/multi-column keys, rebuilt deduplication (`DataFrame.Unique`, `LazyFrame.Unique`, `UniqueKernels`) to distinguish `null` from `0`/`0.0`/`""`, and preserved tie-stability in multi-column `Int32`/`Float64` LSD radix `ArgSort`.
- **Memory & `ValidityMask` Hardening:** Enforced read-only tail-bit masking across all `ValidityMask` paths (`0 <= NullCount <= Length`), ref-counted `NativeMemoryOwner<T>` lifetime with finalizer and overflow checks, and `ValidityMask` propagation to `Float32Series` hardware-accelerated operations.
- **Streaming Multi-Column `JsonReader`, `CsvParser`, `Parquet` & Sealed `LazyFrame` Sinks:** Added streaming and eager NDJSON and JSON-array (`[...]`) readers via `RandomAccess`/`MemoryMappedFile`, quoted CSV multi-line/escaped `""` support, streaming `SinkCsv`/`SinkParquet`/`SinkIpc`, and `Glacier.Formats` (`1.0.1`) Compact Columnar IPC v1 interoperability.
- **Dependency Alignment:** Aligned `Glacier.Formats` `1.0.1`, `Glacier.Storage` `1.1.1`, `Glacier.Gpu` `1.2.1`, `System.Numerics.Tensors` `10.0.12`, and `Parquet.Net` `5.6.1`, with `GpuTarget.Amd` quarantined (`IsAmdAvailable == false`).
